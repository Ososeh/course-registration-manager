# Course Registration Manager

A standard Vite + React JavaScript project for managing student course
registrations.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown in the terminal. Use `Ctrl + Shift + J` in the
browser to view the instructional `console.log()` messages.

## Project structure

- `src/App.jsx` owns the student and filter state.
- `src/components/` contains the reusable interface components.
- `src/main.jsx` mounts the React application.
- `src/App.css` contains the responsive styling.
